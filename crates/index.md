# クレートのドキュメント {#crates-documentation}

Kani には現在、`kani` クレートが同梱されています。このクレートは、ユーザが
ハーネスを書いたり設定したりするための API を提供します。
これらの API は Kani の各バージョンと密接に結びついているので、まだ
<https://crates.io> では公開されていません。

最新のドキュメントはここにあります。
  - [kani](https://model-checking.github.io/kani/crates/doc/kani): このクレートは
  Kani のハーネスを書くための API を提供します。
