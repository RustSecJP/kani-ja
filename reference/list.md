# list コマンド {#list-command}

`list` サブコマンドは、指定したプロジェクトまたはファイルにあるハーネスと契約の概要を表示します。コードベースのどの部分が検証でカバーされているかを把握したり、検証の進み具合を追ったりするのに役立ちます。

## 使い方 {#usage}
基本的な使い方としては、`cargo kani list` または `kani list <FILE>` を実行します。現在のオプションは次のとおりです。
- `--format [pretty|markdown|json]`: 出力形式を選びます
- `--std`: 標準ライブラリのハーネスと契約を一覧表示します（スタンドアロンの `kani` のみ）

デフォルトの形式は `pretty` で、たとえば次のような表を端末に表示します。

```
Kani Rust Verifier 0.65.0 (standalone)

Contracts:
+-------+----------+-------------------------------+----------------------------------------------------------------+
|       | Crate    | Function                      | Contract Harnesses (#[kani::proof_for_contract])               |
+=================================================================================================================+
|       | my_crate | example::implementation::bar  | example::verify::check_bar                                     |
|-------+----------+-------------------------------+----------------------------------------------------------------|
|       | my_crate | example::implementation::foo  | example::verify::check_foo_u32, example::verify::check_foo_u64 |
|-------+----------+-------------------------------+----------------------------------------------------------------|
|       | my_crate | example::implementation::func | example::verify::check_func                                    |
|-------+----------+-------------------------------+----------------------------------------------------------------|
|       | my_crate | example::prep::parse          | NONE                                                           |
|-------+----------+-------------------------------+----------------------------------------------------------------|
| Total |          | 4                             | 4                                                              |
+-------+----------+-------------------------------+----------------------------------------------------------------+

Standard Harnesses (#[kani::proof]):
+-------+----------+-------------------------------+
|       | Crate    | Harness                       |
+==================================================+
|       | my_crate | example::verify::check_modify |
|-------+----------+-------------------------------|
|       | my_crate | example::verify::check_new    |
|-------+----------+-------------------------------|
| Total |          | 2                             |
+-------+----------+-------------------------------+
```

「Contracts」の表は、契約のアトリビュート（`#[requires]`、`#[ensures]`、`modifies`）を持つ関数と、それらの関数に対してどのハーネスがあるかを示します。
「Standard Harnesses」の表は、見つかったすべての `#[kani::proof]` ハーネスを一覧表示します。

`markdown` オプションと `json` オプションは、同じ情報をそれぞれ Markdown ファイルと JSON ファイルに書き出します。

`--std` を使うときは、指定したパスが標準ライブラリのローカルコピーを指すようにしてください。例: `kani list --std rust/library`。（標準ライブラリのコンパイルは通常の Rust プロジェクトのコンパイルとは[仕組みが異なる](https://doc.rust-lang.org/cargo/reference/unstable.html#build-std)ため、別のオプションになっています。）

オプションの完全な一覧を見るには、`kani list --help` を実行してください。

## 自動ハーネス (Autoharness) {#autoharness}
デフォルトでは、このサブコマンドは手動で書いたハーネスしか検出しないことに注意してください。[実験的な autoharness 機能](./experimental/autoharness.html)は `--list` 引数を受け付けます。これを使うと、手動のハーネスと自動生成されたハーネスの両方についてこのサブコマンドを実行します。
